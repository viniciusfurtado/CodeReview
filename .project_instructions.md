# AI Code Review SaaS

## Overview
- SaaS de revisão de código com IA para Pull Requests do GitHub
- Toda a interface em Português Brasileiro (pt-BR)

## Tech Stack
- Next.js 16 App Router + TypeScript strict
- Prisma ORM + PostgreSQL
- NextAuth v5 (Auth.js) com GitHub Provider
- Tailwind CSS + shadcn-style components
- @octokit/rest + jsonwebtoken para GitHub App

## Architecture
- `auth.ts` (root) — Auth.js v5 config com PrismaAdapter customizado
- `lib/db.ts` — Prisma client singleton
- `lib/github/auth.ts` — GitHub App JWT generation + installation token cache
- `lib/github/webhook.ts` — Webhook signature validation
- Auth protection via `auth()` in server components (no middleware/proxy)

## Domain Models
- Organization, User, OrganizationMember, Repository
- NextAuth tables: Account, Session, VerificationToken

## Auth Flow
- GitHub OAuth via NextAuth v5 GitHub provider
- On sign-in: syncs user orgs + creates OWNER memberships
- JWT strategy with userId + primaryOrgId in token
- Protected routes: /dashboard/* (checked in layout via auth() + redirect)

## Env Vars (placeholder for preview)
- GITHUB_APP_CLIENT_ID, GITHUB_APP_CLIENT_SECRET — placeholders
- GITHUB_APP_ID, GITHUB_APP_PRIVATE_KEY_BASE64 — self-generated RSA key
- GITHUB_WEBHOOK_SECRET, GITHUB_APP_NAME — placeholders
- Real GitHub App credentials needed for full auth flow
